# Remotely Save 使用环境同步更新

本仓库保存基于 Remotely Save 0.5.25 开发的使用环境迁移更新。插件名称和 ID 保持原样，定制版版本号为 **0.5.26**。未提交 Obsidian 插件市场。

## 功能

- 同步主题、CSS 片段、仓库内字号和配色、快捷键、编辑器及核心插件设置。
- 同步社区插件的实际程序、样式、资源、配置和启用列表。
- 新设备“从云端恢复完整使用环境”明确使用云端配置，避免新设备较新的默认设置反向覆盖旧设备使用习惯。
- 全量下载并检查后再应用，替换前备份，失败时尝试回滚；恢复插件文件时检查程序完整性。
- 配置下载后提示重启，并暂停后续同步，避免内存中的旧设置被上传。
- Remotely Save 自身的程序、连接配置、恢复备份及设备窗口布局留在本机。
- 修复生产打包的手机端 Node 模块引用与动态分包问题。

## 上游与补丁

上游：<https://github.com/remotely-save/remotely-save>

基线提交：`34db181af002f8d71ea0a87e7965abc57b294914`。

`environment-sync-apache.patch` 可在对应的上游检出目录中通过 `git apply --check` 检查，随后通过 `git apply` 应用。新增模块和测试需要位于补丁指定的 `src/`、`tests/` 路径；根目录的副本只是为了便于审阅。

原项目的 `pro/` 目录使用 **PolyForm Strict 1.0.0**，与其 Apache-2.0 基础代码的许可不同。因此这里**不提供原 Pro 源码、完整项目副本、编译插件或安装包**。单独的 Pro 接入补丁只包含本次新写的插入内容，没有原始 Pro 源码上下文，也不授予修改或再分发原 Pro 代码的权利。需要先取得必要的额外授权，才能在该目录应用修改或发布包含它的产物。零上下文补丁的技术格式需要 Git 的 `--unidiff-zero` 参数。

本仓库用于保存和审阅更新，不是可直接安装的独立插件。不能仅应用 Apache 补丁后就把缺少 Pro 过滤接入的构建当作完整发布版。

## 验证记录

对本机完整集成版本执行过：80 项自动化测试、TypeScript 检查、webpack 和 esbuild 生产构建。最终生产包通过临时 WebDAV HTTP 服务测试，覆盖桌面/iOS 接口模拟、未加密及 OpenSSL 加密恢复，并检查加载及恢复无需桌面 Node 模块。

测试所用的上游 Git LFS 二进制样本按原始摘要验证后临时下载，没有包含在本仓库。尚未进行 iPhone 真机验收。

## 范围

系统字体、系统权限、仓库之外的应用级偏好不在同步范围内。桌面专用插件的文件可以复制到手机，但是否可运行取决于插件的平台支持。配置按整个文件同步，不进行字段级合并。

本仓库不包含个人仓库、WebDAV 账号、密码、令牌、加密密码或用户配置。原作者和许可说明见 `NOTICE.txt`。
